# Security Policy

Prompt Vault is a **PRE-ALPHA SOURCE PREVIEW** with no supported release or production deployment.

## Private vulnerability reports

Do **not** open a public issue or discussion containing vulnerability details.

Use GitHub Private Vulnerability Reporting through the repository **Security** tab and select **Report a vulnerability**. Before the repository is made public, the owner must confirm that this private reporting feature is enabled and visible.

If **Report a vulnerability** is not available, do not disclose details publicly. Wait for the repository owner to publish a verified private reporting channel.

Include the affected commit or branch, impact, reproduction steps, configuration, and any known mitigation.

The detailed policy is maintained at [docs/security/policies/security.md](docs/security/policies/security.md).
