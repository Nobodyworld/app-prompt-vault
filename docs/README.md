# Documentation Index

This directory groups all reference material for Prompt Vault. Each subfolder collects a specific class of documents to keep the
root project tidy and make topics easy to discover.

- [`architecture/`](architecture/README.md) – Runtime and deployment views, plus the latest architecture overview.
- [`guides/`](guides/README.md) – Task-focused walkthroughs for extending and operating the product.
- [`operations/`](operations/README.md) – Runbooks, automation guardrails, and telemetry references for on-call teams.
- [`policies/`](policies/README.md) – Governance, compliance, and security policies that apply to Prompt Vault.
- [`releases/`](releases/README.md) – Release notes and upgrade guidance for each published version.
- [`reports/`](reports/README.md) – Stewardship reports and status updates that feed roadmap planning.

Additional single-file deep dives remain at the root of `docs/` for quick access during audits (for example
[`workflows.md`](workflows.md) and [`future-proofing.md`](future-proofing.md)).
