# Architecture Docs

The architecture section captures how Prompt Vault is assembled across services and clients.

- [`overview.md`](overview.md) diagrams the main flows between the domain service, web/desktop clients, and telemetry surfaces.
- System evolution proposals and ADRs should be added here to keep implementation decisions close to the technical diagrams.

When updating service boundaries or platform support, refresh the architecture overview and cross-link relevant design notes from
`docs/future-proofing.md`.
