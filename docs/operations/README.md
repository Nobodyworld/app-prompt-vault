# Operations Runbooks

Runbooks and automation policies live here so on-call engineers have a single source of truth for operating Prompt Vault.

- [`automation.md`](automation.md) documents guardrails and required tooling for routine maintenance.
- [`automation-roles.md`](automation-roles.md) clarifies responsibilities across the automation roster.
- [`telemetry.md`](telemetry.md) describes metrics, tracing, and health-check endpoints.

Update these documents whenever observability surfaces or operational expectations change. Cross-link major updates in
[`docs/reports/stewards-report.md`](../reports/stewards-report.md).
